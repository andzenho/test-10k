# Сайт ПАПКИ

Одна длинная страница под телефон, 12 блоков. Без сборки: `index.html`, `styles.css`, `main.js`.

Посмотреть на своём компьютере:

```bash
python3 -m http.server 8766
```

и открыть `http://localhost:8766`.

## Что заменить перед запуском

- **Фон первого экрана.** Положить картинку из нейросети в `img/hero.webp` (вертикальная, 1080×1920, лицо в верхней половине) и в `styles.css` у `.hero__bg` раскомментировать строку с `url(img/hero.webp)`. Подпись-заглушку «Место под фон с лицом» убрать из `index.html`.
- **Оплата только в личке.** Кнопка «Оплатить ПАПКУ» (`id="pay"`) открывает чат `t.me/andzen200`. Если сделать в Телеграме ссылку с готовым текстом (`t.me/m/…`), подставить её туда.
- **Скрин к кейсу «Мой Телеграм-канал».** Положить в `img/` и вставить на место блока `shot--empty`.
- **Имя клиента в кейсе психотерапевта.** Сейчас без имени, см. комментарий в `index.html`.

## Правила текста

- Заголовки, плашки и кнопки без точки и без двоеточия в конце.
- Пункты списков, которые продолжают фразу, — со строчной буквы, через «;», в конце точка. Короткие пункты-ярлыки — без знаков.
- Тире длинное «—» с пробелами, перед ним неразрывный пробел. Диапазоны — короткое «–» без пробелов: 2025–2026, 1–3.
- Кавычки «ёлочки», внутри — „лапки“.
- Числа: разряды через пробел (14 990), знак после числа через неразрывный пробел (14 990 ₽), процент слитно (90%), доллар перед числом слитно ($1 млн). «Больше чем» — плюсом после числа: $1+ млн, 5+ млн ₽.
- Короткие предлоги и союзы не висят в конце строки, число не отрывается от слова после него. Это делает `main.js`, руками ставить не нужно.
- Переносы по слогам выключены: на узком экране они мешают читать.
- Капс только в заголовках и коротких плашках, с разрядкой.

## Как устроено

- Цвета, шрифты и размеры — переменные в начале `styles.css`.
- Кнопки «Хочу в ПАПКУ» ведут к блоку «Условия доступа» (`#dostup`).
- `main.js` ставит неразрывные пробелы после коротких слов и плавно показывает блоки при прокрутке. Без него страница тоже работает.
- Заголовки: Bebas Neue (`fonts/`), текст: Montserrat (Google Fonts).
